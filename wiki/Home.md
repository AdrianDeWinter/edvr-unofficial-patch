# ED Unofficial Patch

ED-UP (formerly EDVR) is a free add-on for Elite Dangerous: Odyssey. It makes the picture steadier and sharper in a headset and on a monitor, draws the on-foot game in stereo, and corrects problems that are fine on a screen and wrong in a headset.

You install it with one program, then start the game from Steam, Epic, or Frontier's launcher as you already do. The first install takes a few minutes.

This wiki is the player guide. The [README](https://github.com/characterecho-sean/ed-unofficial-patch) on the project page is the short introduction. Each page here is one job. Release 0.22.2 was made for Odyssey build 334925. The notes on each release name the build that release matches.

## Before you download

The launcher accepts Odyssey. It stops when it finds the older Horizons client.

Close Elite before you install. The launcher lists every change and waits for a yes. It copies each file it replaces into `edup_backup` in the game folder.

After Frontier updates the game, Elite still starts. A fix that no longer matches that update turns itself off, and the log names it. Walking around in stereo needs the build named in the release notes.

ED-UP leaves your Frontier account, ships, cargo, and credits alone. Frontier has not endorsed it. A tip is welcome at [Ko-fi](https://ko-fi.com/seancharacterecho) and is never required.

A problem with a log attached goes on [an issue](https://github.com/characterecho-sean/ed-unofficial-patch/issues/new/choose). Setup questions fit the [Discord](https://discord.gg/AWJ6djKKzr).
